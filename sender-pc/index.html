Projector Cast

Mirror this PC's screen and sound to your projector.

Pick a window (for example the browser playing the match) to keep using the rest of your PC while only that window plays on the projector. Keep that window open (not minimised).

Sound casting works on Windows only.

Advanced

Changing the capture method restarts this app.

The projector will show an install screen. Select Install with the remote, then open Projector Cast again. (The first time, Android may ask you to allow installing from Projector Cast. Allow it.)
